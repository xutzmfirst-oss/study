# Быстрый перекус

Простой многостраничный сайт с рецептами для студентов. Публичный адрес: https://xutzmfirst-oss.github.io/study/.

Пять основных разделов: главная, завтраки, обеды, ужины и избранное. Девять отдельных страниц рецептов, страница о проекте и страница ошибки. Сайт работает на GitHub Pages без сборки, внешних библиотек и сервера приложений. Все иллюстрации локальные SVG.

## Аналитика

Подключение подготовлено в `assets/analytics.js`, а публичные настройки хранятся в `assets/analytics-config.js`. По умолчанию внешние счётчики выключены: сначала зарегистрируйте сайт в сервисах и внесите реальные идентификаторы и адреса логотипов из кабинетов. Пароли и токены в репозиторий не добавляются.

События `favoriteAdd` и `timerStart` передаются в Rambler методом `top100Counter.trackEvent`, в Mail.ru — методом `_tmr.push` с `type: 'reachGoal'`. В Mail.ru зарегистрируйте две цели JavaScript с такими же именами; в Rambler создайте целевые события и включите для них конверсии. LiveInternet получает просмотры страниц.

Счётчики и их изображения загружаются только после разрешения посетителя. При проверке разрешите статистику в настройках приватности. Отказавшиеся пользователи не учитываются внешними счётчиками. Существующие события до согласия не отправляются задним числом.

## Функции

- Поиск по названию рецепта и фильтры до 10 и до 15 минут.
- Избранное в localStorage этого браузера, синхронизация вкладок.
- Список ингредиентов с галочками, без отправки данных.
- Таймер с паузой и сбросом. В фоне отсчёт корректируется по времени; при закрытии страницы таймер прекращается.
- Мобильная вёрстка, доступная навигация с клавиатуры, reduced motion.

## Проверка

Откройте сайт через локальный HTTP-сервер. Проверьте поиск, сохранение рецепта, переход в избранное, перезагрузку, запуск и паузу таймера. Без заполненных настроек аналитики запросов к внешним счётчикам быть не должно.
